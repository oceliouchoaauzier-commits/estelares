# 🌟 ESTELARES - Agente Pessoal Modular

**Versão:** 0.1.0  
**Status:** 🔨 Em Desenvolvimento

## 📋 O que é?

**ESTELARES** é uma arquitetura modular para criar um agente pessoal inteligente.

### ✨ Características
- ✅ Arquitetura Modular
- ✅ Sem Credenciais no Frontend
- ✅ Interface Responsiva
- ✅ Suporte a Voz
- ✅ Sistema de Comandos
- ✅ Memória Persistente

## 🚀 Como Usar

```bash
git clone https://github.com/oceliouchoaauzier-commits/estelares.git
cd estelares
python -m http.server 8000
```

Acesse: http://localhost:8000

## 📚 Módulos

- **Core** - Núcleo central
- **Chat** - Histórico de mensagens
- **Memory** - Persistência local
- **Commands** - Sistema de comandos
- **Tools** - Ferramentas seguras
- **Voice** - Web Speech API
- **AI** - Abstração para IA
- **App** - Integração
